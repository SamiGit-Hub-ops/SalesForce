# Apex OOP Fundamentals

This repository contains foundational code examples demonstrating Object-Oriented Programming (OOP) patterns within Salesforce Apex.

## Key Features Covered
* **Constructor Chaining**: Maximizing code reuse during object initialization.
* **Static Initialization Blocks**: Safely assigning values to static final constants at runtime.
* **Scope Differentiation**: Visualizing the operational boundaries between static methods and instance methods.

## Getting Started
Deploy the classes folder to your Salesforce scratch org or sandbox using the Salesforce CLI:
```bash
sf project deploy start
```
