# Apex Encapsulation & Utility Pattern

This repository demonstrates the core OOP concept of **encapsulation** in Salesforce Apex. 

## Key Concepts
* **Encapsulation**: Private static helper methods hide structural calculations from the outside world.
* **Instance Control**: A single public instance method handles operational execution.
* **Separation of Concerns**: Mathematical calculations are isolated from logic-logging operations.

## Deployment
Deploy the components to your Salesforce Org:
```bash
sf project deploy start
```
